# CNN and decoder FPGA assets

The source folders retain their original relative layout so numerical vectors and generated RTL remain usable.

| Folder | Contents |
|---|---|
| cnn_hls/ | cnn_engine.cpp, program, trained coefficients, three input vectors, expected outputs, synthesis script |
| decoder_hls/ | Integer box decoder, trained anchor metadata, reference cases, and checks |
| cnn_rtl_simulation/ and decoder_rtl/ | Generated RTL and the original core simulation layout |
| cnn_rtl_simulation/ | Saved full-core RTL simulation harness and expected data |
| cnn_routed_core/ | Earlier isolated-core routed reports |

Use Vitis HLS 2026.1 for the retained original HLS scripts. The separate October 29 board source includes RTL generated by 2023.2. Preserve that tool distinction when comparing a regenerated design.

Run synthesis from an isolated copy of the selected HLS directory because its script creates a project relative to the working directory. Example from the repository root in PowerShell, using a new build path and an installed Vitis HLS executable on PATH.

```powershell
New-Item -ItemType Directory -Path builds/cnn_hls
Copy-Item model/fpga/cnn_hls/* builds/cnn_hls -Recurse
Push-Location builds/cnn_hls
vitis_hls -f synth.tcl
Pop-Location
```

This can be a heavy job. Preserve at least 1.5 GiB free RAM and run one compiler at a time. Do not use the example as an automatic build or programming step.

The earlier isolated core routed at 100 MHz with 26,828 LUTs, 266 DSPs, and 98 RAMB36 plus 12 RAMB18. This result measures that core. The current integrated-binary description is in [artifacts](../../artifacts/README.md). The older board source and its own reports are under hardware/genesys2/reference_oct29.

Exact input packing and arithmetic are documented in cnn_hls and the older board pack_image_to_hex.py tool. Preserve RGB order, Q14 scaling, zero-padded channels, head ordering, anchors, and crop coordinate mapping.
